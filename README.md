# KHMlight

Нативний Android-застосунок для перегляду графіків погодинних відключень електроенергії (ГПВ) у Хмельницькому та Хмельницькій області в стилі **Material 3 Expressive + Material You**.

> **Версія:** `1.0` (`v1.0`)

---

## Основні можливості

### Застосунок
* **Моя черга** — живий статус електропостачання (*«Є світло»* / *«Немає світла»*), зворотний відлік до наступної зміни, інтерактивна 24-годинна шкала з пульсуючим маркером поточного часу, свайп між **Сьогодні** та **Завтра**, а також стилізована картка інтервалів із бейджами статусу (`Зараз`, `Заплановано`, `Минуло`) та оперативними повідомленнями ХОЕ.
* **Усі черги** — усі підчерги (`1.1` – `6.2`) у природному порядку з міні-шкалами доби та підсвіткою обраної черги.
* **Історія** — перегляд збережених графіків за попередні дні з фільтром «Лише моя черга» / «Усі черги» та деталями по кожному дню.
* **Material You & Expressive Motion** — підтримка динамічних кольорів шпалер Android 12+, світлої/темної теми, шрифту Google Sans, адаптивної та тематичної монохромної іконки, а також плавних Material 3 анімацій.
* **Офлайн-кеш та ETag** — дані кешуються локально й оновлюються через HTTP `ETag / 304 Not Modified` без зайвого трафіку.

### Віджети робочого столу (Material 3 Expressive)
Підтримуються 4 формати віджетів із живим налаштуванням (`WidgetConfigActivity`):
* **1×1 Міні** — компактна геометрична фігура з кольором обраної палітри, індикатором стану, таймером та часом наступної події (`О xx:xx`).
* **1×4 Signal Wave** — горизонтальний віджет із реальною осцилограмою графіка доби, фігурним Time Badge та пігулкою наступної події.
* **2×2 Статус** — адаптивна картка (для квадратних і витягнутих сіток на кшталт Pixel Launcher) із великим Time Badge, Signal Wave та підсумком годин за добу.
* **4×2 Дашборд** — розширений віджет із повною шкалою Signal Wave `00:00–24:00` та капсулами інтервалів.

Для кожного віджета можна окремо обрати:
* **Форму елемента:** `B1 Squircle`, `B2 Wave`, `B3 Blob`, `B4 Cloud`, `B5 Organic`;
* **Палітру та тему:** `Material You`, `Лаванда`, `Океан`, `М'ята`, `Бурштин`, `Кварц`, `Графіт` + `Системна / Світла / Темна`;
* **Окрему чергу** або автоматичну синхронізацію з основною чергою застосунку.

### Фонова робота та сповіщення
* Попередження перед відключенням та перед включенням світла (за `15 / 30 / 60 хв`).
* Сповіщення про зміни графіка на сьогодні та публікацію графіка на завтра.
* Режим **«Тихі години»** (`23:00 – 07:00`).
* Точне перемикання стану на віджетах через `AlarmManager` + періодична синхронізація через `WorkManager` із відновленням після перезавантаження пристрою (`BootReceiver`).

## Джерело даних

Застосунок отримує структуровані графіки у форматі JSON із репозиторію парсера [khm_outage_parser](https://github.com/frankov-dev/khm_outage_parser) (дані Хмельницькобленерго — `hoe.com.ua`).

---

## Технології

* **Мова:** Kotlin (JVM 11 + core library desugaring)
* **SDK:** `minSdk = 21` (Android 5.0+), `compileSdk = 37`, `targetSdk = 37`
* **UI:** ViewBinding, Material Components for Android (Material 3 / Dynamic Colors), `ViewPager2`, `RecyclerView`, кастомний Canvas-рендеринг для віджетів і 24h-шкали
* **Фонова робота:** WorkManager, AlarmManager, Coroutines & StateFlow
